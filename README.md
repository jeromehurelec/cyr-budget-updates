# CyR Budget — mises à jour

Ce dépôt public distribue uniquement les APK signés de CyR Budget et leurs informations de version.

Télécharger la dernière version dans Releases. Installer le nouvel APK sans désinstaller l’application précédente pour conserver les données. À partir de la version 1.1.0, l’application recherche et télécharge ses nouvelles versions automatiquement ; Android demande de confirmer leur installation.

Les sources sont conservées dans un dépôt privé. Aucune donnée financière, clé de signature ou configuration personnelle n’est publiée ici. Le budget reste utilisable hors ligne. Internet est utilisé uniquement pour obtenir les nouvelles versions.
